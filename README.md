## ⚙️ Development Guide

This is a modern **Next.js 16** application styled using **Tailwind CSS v4** and animated with **Framer Motion**.

### **Prerequisites**
Make sure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### **Setup Instructions**

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ITMohanraj/mohanraj-portfolio.git
   cd mohanraj-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the live local application.

4. **Build for production:**
   ```bash
   npm run build
   ```
